# sdkbump

Checks a native iOS, Flutter or React Native/Expo project for what the iOS 27 SDK changes, starting
with the UIScene life cycle, and says which fix applies to each finding.

Work in progress: nothing is published yet, and this README is replaced by the full one before the
first release. Background:
[Transitioning to the UIKit scene-based life cycle](https://developer.apple.com/documentation/uikit/transitioning-to-the-uikit-scene-based-life-cycle).
