Fails to launch when built with the iOS 27 SDK.

ERROR    SCN001 No scene configuration
         ios/Runner/Info.plist
         Info.plist has no UIApplicationSceneManifest, and AppDelegate does not implement
         application(_:configurationForConnecting:options:). Built with the iOS 27 SDK, the app
         stops at launch: "UIScene life cycle is required for apps built with this SDK". Flutter
         will not migrate it automatically: ios/Runner/AppDelegate.swift differs from the templates
         Flutter migrates.
         Fix: [A] Migrate the Flutter app by hand

WARNING  SCN003 application(_:open:options:) is not called with scenes
         ios/Runner/AppDelegate.swift:28
         UIKit does not call this method once the app uses scenes. Use scene(_:openURLContexts:),
         and connectionOptions.urlContexts in scene(_:willConnectTo:options:) for a link that
         launches the app.
         Fix: [B] Handle it in a FlutterSceneDelegate subclass

WARNING  SCN004 Root view controller read from the app delegate's window
         ios/Runner/AppDelegate.swift:10
         UIKit does not set the app delegate's window once a scene owns the window, and
         application(_:didFinishLaunchingWithOptions:) runs before any scene connects; reading its
         root view controller finds nil, and a forced cast of it crashes.
         Fix: [C] Create channels from the engine bridge

How to fix

[A]      Migrate the Flutter app by hand
         1. Conform AppDelegate to FlutterImplicitEngineDelegate and move
            GeneratedPluginRegistrant.register, method channels and platform views into
            didInitializeImplicitFlutterEngine(_:).
         2. Add UIApplicationSceneManifest to ios/Runner/Info.plist with a configuration whose
            UISceneDelegateClassName is FlutterSceneDelegate and UISceneStoryboardFile is Main.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/flutter.md

[B]      Handle it in a FlutterSceneDelegate subclass
         1. Create SceneDelegate: FlutterSceneDelegate, name it in UISceneDelegateClassName, and
            override the scene delegate method named in the finding, calling super so plugins still
            receive the event.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/flutter.md

[C]      Create channels from the engine bridge
         1. Create method channels in didInitializeImplicitFlutterEngine(_:) with
            engineBridge.applicationRegistrar.messenger() instead of reading
            window?.rootViewController.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/flutter.md
