How to fix

[A]      Upgrade to React Native 0.88
         1. React Native 0.88 is stable (0.88.0 on npm since 15 October 2026; release post of 19
            October 2026) and supports the UIScene life cycle without breaking the AppDelegate path.
            0.87.1 and earlier have no scene support, and the React Native team will not backport
            it.
         2. Move the React Native entry point from AppDelegate to a SceneDelegate
            (RCTReactNativeFactory's new
            startReactNativeWithModuleName:inWindow:connectionOptions:), forward the scene's URL and
            user-activity callbacks to RCTLinkingManager, and add UIApplicationSceneManifest to
            Info.plist. The 0.88 template and the upgrade helper show the change in
            SceneDelegate.swift and Info.plist.
         3. Keep UIApplicationSupportsMultipleScenes false: 0.88 supports one scene, and at launch
            it forwards only the first URL context or user activity. The window can be resized;
            Dimensions.get() and useWindowDimensions() follow it.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/react-native-expo.md

[B]      Add a SceneDelegate by hand
         1. Port the 0.88 template's SceneDelegate and Info.plist manifest to your version: create
            the window from the UIWindowScene and start React Native into it there.
         2. Before 0.88, startReactNative takes launch options, not connection options, so convert
            the connection options of a link that launches the app.
         3. The React Native team gives deep links through the scene delegate and Dimensions for a
            resizable window as the reasons it does not backport 0.88's change; check both in your
            port.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/react-native-expo.md
