HANDLED  SCN001 No scene configuration
         ios/RN087App/Info.plist
         Info.plist has no UIApplicationSceneManifest, and AppDelegate does not implement
         application(_:configurationForConnecting:options:). Built with the iOS 27 SDK, the app
         stops at launch: "UIScene life cycle is required for apps built with this SDK".
         Handled at run time by react-native-uiscene-bridge 0.1.0. Limits: Tested in the simulator
         only, not on a device (its README). One window: iPad multiwindow needs real scene support.
         Universal links, Handoff and quick actions were not tested (its README). iOS only: Mac
         Catalyst is untested; tvOS and visionOS are not supported.
         Fix: [A] Upgrade to React Native 0.88; or [B] Add a SceneDelegate by hand

         ios/RN087App/AppDelegate.swift:24
         AppDelegate creates the window with UIWindow(frame:). With a scene, UIKit does not show a

         Handled at run time by react-native-uiscene-bridge 0.1.0. Limits: Tested in the simulator

         Universal links, Handoff and quick actions were not tested (its README). iOS only: Mac

How to fix

[A]      Upgrade to React Native 0.88
         1. React Native 0.88 moves the window and React Native start-up to a SceneDelegate and adds
            the scene manifest. On 15 October 2026 it is a release candidate (0.88.0-rc.6 on npm's
            next tag); 0.87.1 and earlier have no scene support.
         2. Compare ios/ with the 0.88 template (AppDelegate.swift, SceneDelegate.swift, Info.plist)
            when you upgrade.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/react-native-expo.md

[B]      Add a SceneDelegate by hand
         1. Port the 0.88 template's SceneDelegate and Info.plist manifest to your version: create
            the window from the UIWindowScene and start React Native into it there.
         2. Before 0.88, startReactNative takes launch options, not connection options, so convert
            the connection options of a link that launches the app.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/react-native-expo.md
