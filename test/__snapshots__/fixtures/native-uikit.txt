Fails to launch when built with the iOS 27 SDK.

ERROR    SCN001 No scene configuration
         Shelf/Info.plist
         Info.plist has no UIApplicationSceneManifest, and AppDelegate does not implement
         application(_:configurationForConnecting:options:). Built with the iOS 27 SDK, the app
         stops at launch: "UIScene life cycle is required for apps built with this SDK".
         Fix: [A] Adopt a scene delegate

ERROR    SCN002 Window created in the app delegate
         Shelf/AppDelegate.swift:12
         AppDelegate creates the window with UIWindow(frame:). With a scene, UIKit does not show a
         window that belongs to no scene, and the app opens to a black screen.
         Fix: [B] Create the window in the scene delegate

         Fix: [C] Move it to the scene delegate

How to fix

[A]      Adopt a scene delegate
         1. Add a SceneDelegate class (UIResponder, UIWindowSceneDelegate) that creates the window
            in scene(_:willConnectTo:options:).
         2. Add UIApplicationSceneManifest to Info.plist with a UIWindowSceneSessionRoleApplication
            configuration whose UISceneDelegateClassName is $(PRODUCT_MODULE_NAME).SceneDelegate, or
            implement application(_:configurationForConnecting:options:).
         3. Move the app delegate methods sdkbump lists under SCN003 to the scene delegate.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/native-ios.md

[B]      Create the window in the scene delegate
         1. In scene(_:willConnectTo:options:), create the window with UIWindow(windowScene:), set
            its root view controller and call makeKeyAndVisible().
         2. Remove the window creation from application(_:didFinishLaunchingWithOptions:).
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/native-ios.md

[C]      Move it to the scene delegate
         1. Implement the scene delegate method named in the finding and move the code there.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/native-ios.md

[D]      Find the window through the scene
         1. From a view or view controller, use view.window or view.window?.windowScene.
         2. Elsewhere, pick the foreground UIWindowScene from UIApplication.shared.connectedScenes
            and use its keyWindow or windows.
         https://github.com/muhittincamdali/sdkbump/blob/main/docs/guides/native-ios.md
